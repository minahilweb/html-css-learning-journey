# 🌐 HTML5 & CSS3 Learning Journey

Welcome to my web development repository! This project showcases my complete learning journey from scratch, highlighting fundamental concepts, semantic structures, and foundational coding practices.

## 🎯 Purpose of This Project
The goal of this repository is to track my daily progress, master web development core basics, and maintain clean, standardized, and readable code formats for professional growth.

---

## 📂 What's Inside?

Here is a breakdown of the core topics and projects covered in this repository:

* 📁 **my-first-html-website** – My very first website integrating HTML structure, custom CSS styling, and basic JavaScript interactions.
* 📁 **html-forms-practice** – Forms implementation using text fields, buttons, labels, and input validations.
* 📁 **html-images-lists-tables** – Mastery of layout structure including structured data tables (`colspan`, `rowspan`), ordered/unordered lists, and image rendering.
* 📁 **html-video-integration** – Implementing multimedia players using semantic HTML5 `<video>` tags with user controls.
* 📁 **html-inline-block-practice** – Deep dive into CSS display properties, understanding the core behavior of inline vs block-level elements.
